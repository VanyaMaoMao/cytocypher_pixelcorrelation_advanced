# Anti-Overfitting Refactor Changes Report

This document provides a file-by-file and rule-by-rule account of all changes made during the project-wide scientific integrity audit and anti-overfitting refactor relative to baseline commit `ccdc1c8` (`stable/v2-2026-10-20`).

---

## 1. Summary of Refactored Production Files

| File | Primary Responsibility | Summary of Changes |
|---|---|---|
| `pixel_counter/io_utils.py` | Excel ingestion & sampling rate resolution | Added explicit sampling-frequency provenance (`declared_fs`, `implied_fs`, `effective_fs`, `fs_provenance`, `fs_reconciled`) stored in `df.attrs`. |
| `pixel_counter/preprocessing.py` | Multi-row signal concatenation | Propagated `fs_provenance`, `declared_fs`, `implied_fs`, and `fs_reconciled` into segment metadata dictionary. |
| `pixel_counter/v2_signal.py` | PixelCorrelation baseline, noise, & polarity | Removed hard `1.5 <= freq <= 2.4 Hz` frequency-band gate (`R001`, `R002`, `R003`) and all dataset/segment-specific comments; replaced with continuous cycle-compression scaling and antisymmetric rapid-cycle rest-plateau cues. |
| `pixel_counter/qc_v2.py` | PixelCorrelation binary segment QC | Replaced narrow 6D hyper-rectangle carve-out (`R004`) in `detect_incompatible_contraction_directions` with general anti-phase bidirectional oscillation criteria (`h_ratio >= 0.30`, `w_ratio >= 0.60`, `min(med_wu, med_wd) >= 0.08`, `0.38 <= med_phase <= 0.62`). |
| `pixel_counter/calcium_detector.py` | Calcium transient detection & QC (`standard` & `adult`) | Added explicit `raw_prominence_sigma` to `CalciumDetectorParams` (replacing hidden `* 0.43` multiplier `R005`), unified low-SNR false-peak QC (`R006`), passed `primary_dropout` into `compute_normalized_calcium`, and updated `analyze_calcium_pipeline` to honor custom `params`. |
| `pixel_counter/sarcomere_qc.py` | Sarcomere artifact detection & binary QC | Added configurable `SarcomereMeasurementProfile` (`R013`, `R014`), converted sample-based velocity thresholds to `um/s` scaled by `1/fs`, enabled clean quiescent recordings to `PASS` with `0` events (`R018`), removed overfitted `n_accepted <= 12` ceiling on `excessive_reconstruction_dependence` (`R019`), and removed all segment-specific comments (`A Seg 1`, `B Seg 7`, etc.). |
| `pixel_counter/sarcomere_artifact_recovery.py` | Local PCHIP narrow-gap reconstruction & reconciliation | Added `t0: float = 0.0` parameter to `reconstruct_narrow_tracking_artifacts` so `start_time_s` and `end_time_s` are strictly time-origin invariant (`t0 + c / fs`). |
| `pixel_counter/sarcomere_detector.py` | Sarcomere baseline $L_0(t)$, trough detection, & MAIN/SCE classification | Scaled `n_art_core` threshold by `fs` (`max(2, int(round(0.056 * fs)))`, `R024`), removed dead overwritten Pass-1 validation loop (lines 475–491), unified duplicate MAIN/SCE threshold hierarchy passes (`R025`, `R026`), and enforced the documented `T_MAIN` and `T_SCE` floor formulas without hidden `min(floor, alpha * A_ref)` cancellation. |
| `pixel_counter/sarcomere_pipeline.py` | Sarcomere & Sarcomere-Calcium pipeline orchestration | Passed `t0=t0` to `reconstruct_narrow_tracking_artifacts`, honored custom `params` in `analyze_sarcomere_pipeline`, and computed `n_directly_measured`, `n_valid_amplitude`, and `n_lacking_amplitude` directly from `ev_df` across all modes. |
| `pixel_counter/sarcomere_review.py` | Interactive HTML review report generator | Deleted ~1,700 lines of dead unreferenced `SARCOMERE_HTML_TEMPLATE`, aliasing `HTML_TEMPLATE as SARCOMERE_HTML_TEMPLATE` from `run_v2_review_utility.py`. |

## 2. Rule-by-Rule Audit & Refactor Table

| Rule ID | Module & Function | Old Behavior (`ccdc1c8`) | Scientific Flaw | New Behavior (Post-Refactor) | Impact on Detection / QC / API |
|---|---|---|---|---|---|
| `R001` | `v2_signal.py :: compute_baseline_and_noise` | Hard switch at `0.38 <= dom_cycle_s <= 0.68` reducing baseline window to `0.42x` and quantile from `25%` to `18%`, citing `"Seg 25"`. | Step discontinuity at `dom_cycle_s = 0.68 s`; tuned around specific 2 Hz segments. | Continuous cycle-compression scaling `cycle_scale = np.clip(dom_cycle_s / 0.80, 0.45, 1.0)` over `0.22 <= dom_cycle_s <= 0.80 s`. | Smooth transition across pacing rates; zero API change. |
| `R002` | `v2_signal.py :: _rapid_pacing_polarity_tiebreaker` | Gated on `1.5 <= freq <= 2.4 Hz` (`0.416–0.667 s` IBI), explicitly excluding 1 Hz and 3 Hz (`"at 2 Hz"`, `"at 3 Hz"`). | Explicit pacing-group gate designed around IMR90 1 Hz / 2 Hz / 3 Hz cohorts. | Replaced with `_rapid_cycle_polarity_cues` active whenever `0.22 <= dom_cycle_s <= 0.65 s` (`>= 1.54 Hz`), combining rest-plateau variance asymmetry and derivative asymmetry. | Strictly antisymmetric under `x -> -x` across 1 Hz, 2 Hz, and 3 Hz; zero dataset gating. |
| `R003` | `v2_signal.py :: determine_raw_polarity` | Overrode `score_pos`/`score_neg` when `1.5 <= freq <= 2.4` and `ratio < 1.85` (`"like Seg 25 where ratio is 1.57"`). | Dataset-specific threshold tuned to Seg 25's exact ratio `1.57`. | Integrated rapid-cycle rest-plateau and derivative cues with continuous weighting `w_rapid = clip((0.65 - dom_cycle_s) / 0.35, 0.0, 1.0)` when primary cue ratio `< 1.75`. | Preserves polarity antisymmetry and physical rapid-pacing disambiguation without segment-specific cutoffs. |
| `R004` | `qc_v2.py :: detect_incompatible_contraction_directions` | 6-condition conjunction `0.30 <= h_ratio <= 0.60 and 0.11 <= med_wu <= 0.20 and 1.04 * med_wu` citing `"IMR90_2HZ Seg 19, 30"`. | Overfitted hyper-rectangle carving out two specific segments. | General anti-phase bidirectional oscillation check: `h_ratio >= 0.30`, `w_ratio >= 0.60`, `min(med_wu, med_wd) >= 0.08 s`, and `0.38 <= med_phase <= 0.62`. | Rejects genuine bidirectional tracking bounce on general phase/width symmetry grounds. |
| `R005` | `calcium_detector.py :: detect_calcium_candidates` | Hardcoded `params.min_prominence_sigma * 0.43 * raw_sigma` inside candidate prominence check. | Hidden magic multiplier `* 0.43` not exposed in `CalciumDetectorParams`. | Added `raw_prominence_sigma: Optional[float] = None` to `CalciumDetectorParams` (defaulting to `0.50 * min_prominence_sigma` when `None`). | Fully transparent and configurable in `CalciumDetectorParams`. |
| `R006` | `calcium_detector.py :: evaluate_calcium_qc` | Multi-branch heuristics with dataset comments (`"Seg 44 in DISH2ICI"`). | Dataset-specific commentary and fragmented low-SNR gates. | Unified low-SNR / false-peak noise rejection based on `med_snr < 3.5` and `raw_ excursion < 3.2 * sigma_hf`. | Clean, general low-SNR QC logic; clean quiescent calcium traces `PASS` with `0` events. |
| `R013`, `R014` | `sarcomere_qc.py :: detect_sarcomere_artifacts` | Hardcoded `1.28`, `2.18` um FFT rail bounds and sample-based `0.035`, `0.055` step thresholds assuming `250 Hz`. | Implicitly assumed `250 Hz` sampling rate and fixed optical setup; comments cited `"B Seg 18, B Seg 20"`. | Introduced `SarcomereMeasurementProfile` (`fft_rail_min_um=1.28`, `fft_rail_max_um=2.18`, `jump_vel_um_per_s=8.75`, `extreme_vel_um_per_s=13.75`) scaled by `dt = 1.0 / fs`. | Sampling-rate invariant across `125–500 Hz` and configurable via `SarcomereMeasurementProfile`. |
| `R018` | `sarcomere_qc.py :: evaluate_sarcomere_Stage1_qc` | Unconditionally returned `REJECT` (`no_valid_contractions_detected`) whenever `n_accepted == 0`. | Violated the scientific requirement that a clean quiescent cardiomyocyte recording (`0` contractions, low noise, no tracking failure) is a valid biological observation (`PASS` with `0` events), whereas a noisy trace with `0` contractions is `REJECT`. | Added clean quiescent check: when `n_accepted == 0`, if `sigma_hf <= 0.0012 um`, `dn_p98 <= 0.0040 um`, `n_candidates == 0`, `n_clusters == 0`, and `out_of_range_fraction == 0.0`, returns `PASS` (`clean_quiescent_no_contractions`); otherwise returns `REJECT` (`no_valid_contractions_detected`). | Satisfies Metamorphic Test 6 (`test_6_clean_quiescent_vs_noise_dominated_all_analyzers`). |
| `R019` | `sarcomere_qc.py :: evaluate_sarcomere_stage1_qc` | `excessive_reconstruction_dependence` gated on `n_accepted <= 12` with comment `"A Seg 16 has 4/11 = 36%... B Seg 20 has 4/17 = 23.5%"`. | Explicit beat-count ceiling (`<= 12`) engineered to reject A Seg 16 (11 beats) while passing B Seg 20 (17 beats). | Removed the `n_accepted <= 12` ceiling and removed the rule that penalized recordings based on total beat count; uncorrupted troughs stand on their own signal quality while corrupted troughs have `NaN` amplitude (`TIMING_ONLY_UNMEASURED_PEAK`), and true tracking-artifact dominance is governed by `unrecoverable_tracking_artifact_dominance`. | Eliminates beat-count overfitting (`A Seg 16` vs `B Seg 20`). |
| `R024` | `sarcomere_detector.py :: detect_sarcomere_contractions` | Hardcoded `n_art_core > 14` samples (`56 ms` at `250 Hz`). | Sample count not scaled by `fs`. | Scaled by `fs`: `max_art_core_samples = max(2, int(round(0.056 * fs)))`. | Sampling-rate invariant (`test_5_sampling_rate_consistency`). |
| `R025`, `R026` | `sarcomere_detector.py :: detect_sarcomere_contractions` | Contained a dead first validation loop (lines 475–491) immediately overwritten by a second loop (lines 576–612), plus `min(t_abs_main_pct, alpha_ref * a_ref_pct)` which cancelled user-configured `min_pct_shortening_main` floors. | Dead code duplication and hidden floor cancellation violating documented formula `T_MAIN = max(alpha_ref * A_ref, k_main * sigma_pct, min_pct_shortening_main, 100 * min_abs_shortening_main_um / L0, T_SCE)`. | Removed dead Pass-1 loop and enforced the exact documented `T_MAIN` and `T_SCE` formulas. | Honors custom `SarcomereDetectorParams` floors (`test_14_preset_monotonicity_and_custom_params_honored`). |
| `R029` | `sarcomere_artifact_recovery.py` & `sarcomere_pipeline.py` | `reconstruct_narrow_tracking_artifacts` computed `"start_time_s": float(c0 / fs)` without `t0`, and `sarcomere-calcium` mode overwrote `n_directly_measured` with `match_info["n_both"]`. | Violated time-origin invariance (`t0 != 0`) for reconstructed intervals and conflated calcium-matched beats with directly measured sarcomere amplitudes. | Added `t0: float = 0.0` to `reconstruct_narrow_tracking_artifacts` (`t0 + c0 / fs`), and computed `n_directly_measured`, `n_valid_amplitude`, and `n_lacking_amplitude` strictly from `ev_df` in all modes. | Satisfies Metamorphic Tests 1, 7, and 11. |
| `R032` | `sarcomere_review.py` | Retained ~1,700 lines of dead `SARCOMERE_HTML_TEMPLATE` after switching to `HTML_TEMPLATE` from `run_v2_review_utility.py`. | Massive dead-code maintenance hazard. | Removed dead template strings; aliased `from run_v2_review_utility import HTML_TEMPLATE as SARCOMERE_HTML_TEMPLATE`. | Reduced `sarcomere_review.py` by ~1,700 lines with zero behavioral change. |
